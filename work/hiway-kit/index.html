hiway-kit

사람은 기획과 검증 관문에서만 결정하고, AI 에이전트가 프로덕션 수준 코드까지 스스로 끝내는 개발 키트. Anthropic 심사를 거쳐 Claude 플러그인 디렉토리에 등재

배경

코딩 에이전트에게 기능을 맡기면 곧바로 코드부터 쓰고 얼마 뒤 "다 됐습니다"라고 보고합니다. 그런데 아무도 정하지 않은 요구사항은 추측으로 채워져 있고, 돌렸다던 테스트는 실행된 적이 없는 경우가 많았습니다.

문제

에이전트의 완료 보고만으로는 요구사항 충족을 확인할 수 없었습니다. 그렇다고 사람이 매번 옆에서 확인하면 맡길 이유가 없습니다.

만든 것

관문 두 개와 그 사이의 루프입니다.

  • 기획 관문: 큰 작업은 계획부터 세우고 완료 조건을 실행할 수 있는 명령으로 적습니다. 데이터·보안·돈에 닿는 모호함이 있을 때만 멈추고 묻습니다.
  • 구현 루프: AI 에이전트가 승인된 계획을 끝까지 밀고 갑니다. 사람만 답할 수 있는 질문에서만 멈춥니다.
  • 검증 관문: 완료 조건으로 적은 확인 명령이 통과해야 완료로 칩니다. 병합 전에는 작성자와 분리된 컨텍스트에서 리뷰와 보안 스캔을 합니다.
  • Claude Code를 기준으로 만들었고, Codex·Antigravity에는 각 도구가 지원하는 범위 안에서 같은 규칙과 절차를 제공합니다.

틀렸던 것과 고친 것

에이전트가 32개였을 때, "커밋해줘"나 "봐줘" 같은 평범한 말 한마디에 서브에이전트가 불려 나오던 곳이 139곳 있었습니다. 다른 단계로 흡수되거나 쓰이지 않던 에이전트를 정리해 15개로 줄이고 호출 조건을 다시 써서 0곳이 됐습니다. 같은 릴리스에서 문서 편집 때 자동 포맷 훅 지연도 242ms에서 19ms로 줄였습니다(5회 측정 중앙값).

결과

  • 2026년 9월, Anthropic 심사를 거쳐 Claude 플러그인 디렉토리에 등재됐습니다. 이 디렉토리는 claude.ai, Cowork, Claude Code에서 함께 쓰입니다.
  • 전작 claude-code-kit은 Anthropic 커뮤니티 플러그인 마켓플레이스에 등재돼 있습니다.
  • 전작은 결정적 어서션 9종으로 만든 eval 하네스에서 기준선 38/38을 두고 배포했습니다.
