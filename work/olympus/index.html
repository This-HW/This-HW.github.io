에이전트 운영 플랫폼

AI가 기획·실행·평가하고, 사람은 이사회처럼 방향·예산·위험만 결정 (구축 중)

배경

AI에게 일을 맡길수록 사람이 하는 일은 "확인"으로 바뀌었습니다. 확인할 것이 늘면 사람이 병목이 됩니다.

문제

사람이 개입하지 않아도 AI가 일을 기획하고 실행하고 결과로 다시 판단하게 하려면 사람이 무엇을 쥐고 있어야 할지 정해야 했습니다.

만든 것두 번째 버전 구축 중

  • 사람은 이사회처럼 방향·예산·위험만 결정합니다.
  • 일마다 결과가 나오기 전에 가설과 성공·실패 기준을 못 박습니다.
  • AI 러너는 격리된 작업 공간에서 돌아갑니다. 작성자와 검토자는 서로 다른 러너가 맡습니다.
  • 외부 시스템에 영향을 주는 작업은 게이트웨이 하나만 거치고, 필요한 작업은 사람이 휴대폰으로 승인합니다.
  • 첫 버전에서는 로컬·클라우드 모델을 역할별로 배정하고 실패하면 다음 모델로 넘기게 했습니다.

틀렸던 것과 고친 것

  • 첫 버전에서는 AI 작업자 7개가 큐를 나눠 맡는 구조였습니다. 오류로 20만 번 넘게 재시작하는 일이 생겨 접고 하나의 빌드 흐름으로 합쳤습니다.
  • 제가 직접 지시한 로컬 모델 교체도, 측정 전에 정해 둔 탈락 기준(기존보다 3.26배 느리고 메모리 두 배 가까이)에 걸려 철회했습니다.
  • 그 뒤로는 무언가를 바꾸기 전에 "어떤 결과가 나오면 접을지"를 먼저 정합니다.

결과

커밋 4,520건(2026-11-08), 테스트 함수 15,409개(2026-10-28), 첫 번째·두 번째 버전 합계. 첫 실증 대상은 데이터 매체 파이프라인으로 정했습니다(2026-11 기준, 아직 연결 전).
