데이터 매체 파이프라인

공시·한국은행 통계·뉴스 등 공개 데이터로 AI가 영문 기사를 쓰고, 계산은 코드가 하며, 자동 검수를 거쳐 경제 매체와 문화 산업 매체에 발행

배경

공시(DART), 한국은행 경제통계(ECOS), 뉴스 같은 데이터는 공개돼 있지만, 읽기 쉬운 영문 기사로 바꾸려면 사람이 숫자를 계산하고 문장을 쓰고 검수해야 합니다.

문제

LLM이 쓴 기사에는 수치 오류가 섞일 수 있습니다. 그렇다고 모든 기사를 사람이 검수하면 발행이 계속 사람 손에 묶입니다.

만든 것

  • 수집원 8개(공시·한국은행 통계·뉴스 등)에서 모은 데이터를 이슈별로 묶어 LLM이 영문 기사로 다시 씁니다. 한국어판도 함께 냅니다.
  • 계산은 코드가 하고, LLM은 계산하지 않습니다. 전주 데이터가 없으면 전주 대비 값을 만들지 않습니다.
  • 검수는 규칙 검사와 LLM 검사로 합니다. LLM이 숫자가 틀렸다고 지목해도, 코드가 원자료로 다시 계산해 확인해야 반려합니다.
  • 결과는 병합(=발행)·반려·보류로 나뉩니다. 사람은 보류만 봅니다.
  • 정적 사이트로 발행합니다. 배포가 실패하면 자동으로 되돌립니다.

자동 검수로 넘긴 방법

처음에는 사람이 모든 글을 병합했습니다. 자동 검수를 바로 켜지 않고 먼저 사람 판단과 나란히 돌려 비교했습니다. 위험한 불일치가 없는 것을 확인한 뒤에 넘겼습니다(2026-10).

결과

매체 2곳(경제·시장을 다루는 The Korea Pulse, 한국 문화 산업을 다루는 The Korea Wave), 게시 기사 63건(2026-11-08 기준, 영문판·한국어판 각 1벌).
