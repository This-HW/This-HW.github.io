How I work

  • Done is a result I can check.

    When an AI says it's finished, I check with a command before I believe it.

  • Criteria come before results.

    Before changing anything, I write down what result would make me abandon the change.

  • People decide at the gates.

    Only what a person alone can answer (direction, budget, risk) is left to people.

  • Code does the math; models write.

    When an LLM flags a number, code rechecks it against the source.

  • In my own projects, AI writes most of the code; I make the calls.

    I set the scope and what counts as correct, test the assumptions myself, and reject wrong proposals. I keep those decisions, with dates, in decision records.
