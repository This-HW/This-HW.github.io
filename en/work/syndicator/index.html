Data-to-news pipeline

Writes English-language articles from Korean corporate disclosures, central-bank statistics, news and other public data. Code does the arithmetic, and automated review decides what is published on an economy-and-markets site and a Korean culture-industry site

Context

Korean corporate disclosures (DART), Bank of Korea statistics (ECOS) and news are public. Turning them into readable English-language articles still takes a person to compute figures, write and review.

Problem

LLM-written articles can get numbers wrong. Reviewing every article by hand would keep publishing dependent on a person.

What I built

  • Data from eight sources (disclosures, central-bank statistics, news and more) is grouped by issue and rewritten by an LLM into English-language articles, with a Korean edition alongside.
  • Code does the arithmetic; the LLM never calculates. If last week's data is missing, no week-over-week figure is produced.
  • Review combines rule checks with LLM checks. If the LLM flags a possible numerical error, code recomputes the value from the source before the article can be rejected for it.
  • Each article ends as merged (= published), rejected or held. Only held articles go to a person.
  • Articles are published as a static site, with automatic rollback if a deploy fails.

How I handed review to automation

At first a person merged every article. Before enabling automatic publishing, I ran automated review in shadow mode alongside human decisions, and handed over only after it showed no risky disagreements (Oct 2026).

Result

Two outlets — The Korea Pulse (economy and markets) and The Korea Wave (Korea's culture industries) — with 63 published articles as of 2026-11-08, each in English and Korean.
