hiway-kit

A development kit where AI agents carry a task through to production-ready code on their own; people decide only at the planning and verification gates. Accepted into Anthropic's Claude plugin directory after review

Context

Hand a feature to a coding agent and it starts writing code at once, then reports "done" soon after. Often requirements nobody had specified were filled in by guesswork, and the tests it said it ran never ran.

Problem

An agent's completion report was not enough to confirm that the requirements had been met. And if a person has to watch every step, there's no point in handing the work over.

What I built

Two gates with a loop between them.

  • Planning gate: larger tasks start with a plan whose completion criteria are runnable commands. The work stops for a question only when an ambiguity touches data, security or money.
  • Build loop: AI agents push an approved plan through to the end, stopping only for questions that need a person.
  • Verification gate: a task counts as done only when the check commands written as its completion criteria pass. Before merge, a separate context reviews the change and scans it for security issues.
  • Built for Claude Code first; Codex and Antigravity get the same rules and workflow, within what each tool supports.

What I got wrong

With 32 agents, there were 139 trigger points where an everyday phrase like "commit this" or "take a look" would call up a subagent. I folded or removed agents that other steps already covered or that nothing used, cut to 15, and rewrote their trigger conditions; 139 became 0. The same release cut auto-format hook latency on document edits from 242 ms to 19 ms (median of five runs).

Result

  • Accepted into Anthropic's Claude plugin directory after review in September 2026. The directory serves claude.ai, Cowork and Claude Code.
  • Its predecessor, claude-code-kit, is listed in Anthropic's community plugin marketplace.
  • The predecessor shipped with a deterministic eval harness (nine assertion types), passing all 38 baseline checks.
